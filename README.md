## Project Title

## Team Members

## Project Description
This IoT project collects temperature, humidity, and air quality data using ESP32 sensors and uploads the data to a cloud server. The web dashboard displays live environmental data and helps analyze air quality trends.

## Tools and Technologies
- ESP32
- DHT11 Sensor
- NodeMCU
- MQTT Broker
- ThingSpeak / Firebase
- HTML, CSS, JavaScript (Frontend)
